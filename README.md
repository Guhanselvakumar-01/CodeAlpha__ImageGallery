# CodeAlpha Task 1 -- Image Gallery

## 📌 Project Overview

This project is an **Image Gallery** developed using **HTML, CSS, and
JavaScript** as part of the CodeAlpha Frontend Development Internship.

The gallery provides an interactive and responsive way to view images,
with navigation controls, a lightbox view, hover effects, and smooth
transitions.

## 🚀 Features

-   Responsive image gallery layout
-   Next and Previous image navigation
-   Lightbox view for enlarged images
-   Hover effects on gallery images
-   Smooth transitions and animations
-   Responsive design for different screen sizes
-   Image filters or categories *(if implemented)*

## 🛠️ Technologies Used

-   **HTML5** -- Structure of the webpage
-   **CSS3** -- Styling, layout, responsiveness, and animations
-   **JavaScript** -- Gallery navigation and interactive functionality

## 📂 Project Structure

``` text
CodeAlpha_ImageGallery/
│
├── index.html
├── style.css
├── script.js
└── images/
    └── [gallery images]
```


## 🎯 Task Requirements

This project follows the CodeAlpha Task 1 requirements:

-   Design an image gallery using HTML and CSS.
-   Use JavaScript for navigation, including Next/Previous buttons and
    lightbox view.
-   Add hover effects and smooth transitions.
-   Ensure responsive design for different screen sizes.
-   Add image filters or categories as a bonus feature when implemented.

## 📱 Responsive Design

The gallery is designed to adapt to different screen sizes, including:

-   Desktop
-   Laptop
-   Tablet
-   Mobile devices
